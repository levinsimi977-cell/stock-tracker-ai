# StockTracker AI
A smart, AI-powered system for stock market tracking and analysis.

## 🚀 About the Project
**StockTracker AI** is a comprehensive full-stack application designed to help investors track stock performance and gain insights through automated analysis. By combining a robust **Spring Boot** backend with a modern **React/Vite** frontend, the system provides a seamless experience for monitoring financial data and managing portfolios.

## 💡 Key Features
* **Real-time Stock Tracking:** Stay updated with the latest market data as you manage your assets.
* **AI-Powered Analysis:** Smart algorithms that analyze stock trends and patterns.
* **Intuitive Dashboard:** A responsive user interface built for clarity and efficiency.
* **Data Visualization:** Interactive charts and graphs to visualize investment performance.
* **Secure Backend:** Efficient API management with Spring Boot to handle data requests safely.

## 🛠 Tech Stack
* **Frontend:** React, Vite, JavaScript/TypeScript.
* **Backend:** Java, Spring Boot, Maven.
* **Build Tools:** Vite (Frontend), Maven (Backend).
* **Version Control:** Git & GitHub.

⚙️ How to Run Locally
Prerequisites
JDK 17+

Node.js

Backend Setup
Navigate to the backend/ folder.

Run the application:

Bash
   ./mvnw spring-boot:run
Frontend Setup
Navigate to the frontend/ folder.

Install dependencies:

Bash
   npm install
Start the development server:

Bash
   npm run dev
